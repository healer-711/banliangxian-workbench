# 半两闲读写工作台

两个独立的写作工作台：

1. **半两闲** → [index.html](index.html) - 读写创作工作台（6模块）
2. **三分心** → [sanfenxin.html](sanfenxin.html) - 抖音随笔工作台（4模块）

## 在线访问

- 半两闲: https://healer-711.github.io/banliangxian-workbench/index.html
- 三分心: https://healer-711.github.io/banliangxian-workbench/sanfenxin.html

## 功能特点

- 数据本地持久化（localStorage，刷新不丢）
- 支持 Markdown 导出 + 每周提醒
- 移动端优先，可添加到手机桌面
- 莫兰迪配色，卡片风格
